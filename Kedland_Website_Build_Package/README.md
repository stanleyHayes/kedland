# Kedland International School — Website Build Package

**Start here:** open **`Kedland_Website_Build_Package.md`** — it is the full spec and all page copy.

## Folder map
- `Kedland_Website_Build_Package.md` — master spec: brand, sitemap, page-by-page final copy, features, tech, punch list.
- `assets/logo/` — logo (scale only, never redraw): PNGs 64–1791px + `kedland-logo.svg`.
- `assets/favicon/` — `favicon.ico` + PNGs (16–512) + `apple-touch-icon.png`.
- `assets/diagrams/eyfs-areas-of-study.svg` — the EYFS 7 Areas honeycomb (on-brand).
- `assets/brand/brand-tokens.css` — drop-in CSS variables (colour, type, radii, buttons, cards).
- Admission form PDF — not included; create `assets/forms/kedland-admission-form.pdf` when supplied (PENDING).

## The five things to remember
1. It's a school for **young children — Daycare through Primary 3** — the look must say so instantly (see §2).
2. **No online admission form** — parents **download a PDF**; the contact form is the enquiry funnel.
3. **One** minimal dashboard, and its only job is **blog/news** (create/edit/delete) — see §5.4.
4. Build **static/headless** — the old site died from uncontrolled CMS edits; don't repeat it (§6).
5. Anything marked **`[PENDING — client]`** is on the punch list in **§8** — chase it.
